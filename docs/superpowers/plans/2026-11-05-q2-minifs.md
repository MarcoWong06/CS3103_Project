# Q2 Mini File System (`minifs`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete `problem2.c` so `./minifs` implements the CS3103 Problem 2 mini file system on a 1 MiB `virtual_disk.bin`, with a regression runner, boundary tests and README layout docs.

**Architecture:** One C11 source file. Metadata (superblock, `uint16_t` FAT, 128-entry table) lives in memory and is written back to blocks 0–64 after every successful mutation; file data lives in FAT-linked 256-byte blocks 65–4095. One path resolver serves every command; every command validates fully before mutating, and an in-memory snapshot restores state on host I/O failure.

**Tech Stack:** C11 (`gcc -std=c11`), POSIX `getline`, bash + coreutils test runner, Docker image `cs3103-clion-linux:1.0` (Ubuntu 24.04).

**Spec:** `docs/superpowers/specs/2026-11-05-q2-minifs-design.md` — read it first; this plan pins names, messages and tests, the spec gives the reasons.

## Global Constraints

- All code in `problem2.c`; `Makefile` / `CMakeLists.txt` unchanged. `gcc -std=c11 -Wall -Wextra -pedantic -fsyntax-only problem2.c` prints nothing. Add `#include <inttypes.h>` (for `PRIu64`).
- Section order in `problem2.c` (spec §12): constants and on-disk structures → disk I/O → FAT and chain helpers → entry-table helpers → path resolution → `fs_*` commands → starter interpreter → `main`.
- Disk file `virtual_disk.bin`, exactly 1,048,576 bytes; geometry: 256-byte blocks, 4096 blocks, 128 entries, 31-char names.
- Layout constants (exact): `FS_MAGIC 0x464E494Du`, `FS_VERSION 1`, `FAT_START 1`, `FAT_BLOCKS 32`, `ENTRY_START 33`, `ENTRY_BLOCKS 32`, `DATA_START 65`, `ENTRY_SIZE 64`, `FAT_FREE 0x0000`, `FAT_END 0xFFFF`, `FAT_RESERVED 0xFFFE`, `ROOT_ID 0`, `TYPE_UNUSED 0` (existing `TYPE_FILE 1`, `TYPE_DIR 2`). `_Static_assert` that `FAT_BLOCKS * BLOCK_SIZE == NUM_BLOCKS * sizeof(uint16_t)`, `ENTRY_BLOCKS * BLOCK_SIZE == MAX_ENTRIES * ENTRY_SIZE`, `sizeof(file_entry_t) == ENTRY_SIZE`, `sizeof(superblock_t) <= BLOCK_SIZE`.
- No host file per simulated file, no sidecar files, no file-system library.
- Keep the starter interpreter (`execute_command`, `require_arg`, `no_extra_args`, `quoted_content`, `next_token`) and `print_commands`; delete the line `Student starter: file-system operations are TODOs.` from `main`.
- Every new or modified function has a header comment: purpose, inputs, return value / side effects.
- Message strings are `#define` constants (names below); no repeated literal messages.
- Error lines go to **stderr** through `fs_error()`, which calls `fflush(stdout)` first. Format: `Error: <cmd> <path>: <reason>`, or `Error: <cmd>: <reason>` when there is no path. `<path>` is the argument exactly as typed.
- Successful commands print nothing except `format`, `read`, `pwd`, `ls`, `stat`, `df`.
- Tests run on Linux: `docker run --rm -v "$PWD":/workspace -w /workspace cs3103-clion-linux:1.0 bash test_cases/q2/run_tests.sh [case ...]` from the repo root. Below, **RUN** means this command.

### Output formats (exact printf strings)

- `stat` file: `"Name:   %s\n"`, `"Type:   file\n"`, `"Size:   %u bytes\n"`, `"Blocks: %u\n"`
- `stat` directory: `"Name:     %s\n"`, `"Type:     directory\n"`, `"Children: %d\n"` (root's name is `/`)
- `ls`: header `"%-32s %-5s %6s\n"` with `"NAME","TYPE","SIZE"`; file row `"%-32s %-5s %6u\n"` with `name,"file",size`; dir row `"%-32s %-5s %6s\n"` with `name,"dir","-"`; children sorted by `strcmp`
- `df`: `"%-20s%u bytes\n"` `Block size:`; `"%-20s%u\n"` `Total blocks:`; `"%-20s%u (metadata %u + data %u)\n"` `Used blocks:`; `"%-20s%u\n"` `Free blocks:`; `"%-20s%u\n"` `Metadata reserved:`
- `read`: file bytes, then `\n`. `pwd`: absolute path, `/` for root.

### Expected-file shorthand (expand when writing `test_cases/q2/expected/*.out`)

- `FMT` = the format success line. `X×n` = character X repeated n times.
- `STAT(name,size,blocks)` = the 4 file `stat` lines; `STATDIR(name,n)` = the 3 directory `stat` lines.
- `DF(d)` = the 5 `df` lines with used = 65+d, data = d, free = 4031−d.
- `LS[a file 9; b dir]` = the `ls` header then one row per item in that order; `LS[]` = header only.
- `--- label ---` lines are literal separators printed by the runner.

## Review Focus

1. Any command on a missing or invalid disk (not just `df`) → `MSG_UNMOUNTED` error, never a NULL `FILE*` crash. Pinned by case0_format (Task 1) and case12_corrupt (Task 5).
2. Path or name arguments longer than any buffer (300-char component; 127-level path of 4064 chars) → clean error or correct `pwd`, no overflow. Pinned by case7_boundaries and case8_deep_paths (Task 2).
3. Content whose spaces and inner quotes must survive byte for byte → `read` prints it exactly and `stat` size matches. Pinned by case9_file_boundaries (Task 3).
4. A single write larger than the whole data region → no-space error, no integer overflow, nothing changed. Pinned by case11_disk_full (Task 4).
5. Restart right after failed commands → the state on disk equals the pre-failure state. Pinned by the restart half of case11_disk_full (Task 4).

- [ ] **Step 1: Write the runner and the failing case**

`test_cases/q2/run_tests.sh` (make it executable):

```bash
#!/usr/bin/env bash
# Q2 minifs regression tests (Linux). Usage: test_cases/q2/run_tests.sh [case ...]
# A case is a function below or a script test_cases/q2/<case>.txt run in a
# fresh directory. Output (banner and "minifs> " prompts removed) is diffed
# against test_cases/q2/expected/<case>.out; the disk must be exactly 1 MiB.
set -u
ROOT=$(cd "$(dirname "$0")/../.." && pwd)
Q2="$ROOT/test_cases/q2"
BIN="$ROOT/minifs"
DISK_BYTES=1048576
ALL_CASES="case0_format"
WORK=$(mktemp -d)
trap 'rm -rf "$WORK"' EXIT
failures=0

# rep CHAR N: print CHAR repeated N times, no newline
rep() { head -c "$2" /dev/zero | tr '\0' "$1"; }
# fresh_dir NAME: print the path of a new, empty working directory
fresh_dir() { rm -rf "${WORK:?}/$1"; mkdir -p "$WORK/$1"; printf '%s' "$WORK/$1"; }
# run_session DIR FILE: run minifs in DIR with FILE on stdin; print normalised output
run_session() {
    (cd "$1" && "$BIN" < "$2" 2>&1) |
        sed -e '/^Mini File System Simulator$/,/^  exit$/d' -e 's/minifs> //g'
}
# session DIR TEXT: run_session with the commands given as a string
session() { printf '%s' "$2" > "$WORK/cmds.txt"; run_session "$1" "$WORK/cmds.txt"; }
# poke DIR OFFSET ESCAPES: overwrite bytes (printf escapes) at OFFSET of DIR's disk
poke() { printf "$3" | dd of="$1/virtual_disk.bin" bs=1 seek="$2" conv=notrunc status=none; }
# check NAME OUTPUT DIR: diff OUTPUT with expected/NAME.out; DIR's disk must be 1 MiB
check() {
    local ok=1 size
    diff -u "$Q2/expected/$1.out" <(printf '%s\n' "$2") > "$WORK/diff" || ok=0
    size=$(wc -c < "$3/virtual_disk.bin" 2>/dev/null || echo 0)
    [ "$size" -eq "$DISK_BYTES" ] || { echo "disk is $size bytes" >> "$WORK/diff"; ok=0; }
    if [ "$ok" -eq 1 ]; then echo "PASS $1"; else echo "FAIL $1"; cat "$WORK/diff"; failures=$((failures + 1)); fi
}
# script_case NAME: run test_cases/q2/NAME.txt in a fresh directory
script_case() { local d; d=$(fresh_dir "$1"); check "$1" "$(run_session "$d" "$Q2/$1.txt")" "$d"; }

# ---- runner-generated cases ----
case0_format() {
    local d out
    d=$(fresh_dir case0_format)
    out=$(session "$d" $'df\npwd\nls\ncreate a.txt\nread a.txt\nstat /\nformat\ndf\nexit\n')
    out+=$'\n--- restart ---\n'
    out+=$(session "$d" $'df\nformat\ndf\nexit\n')
    check case0_format "$out" "$d"
}

# ---- main ----
warnings=$(gcc -std=c11 -Wall -Wextra -pedantic -fsyntax-only "$ROOT/problem2.c" 2>&1)
[ -z "$warnings" ] || { echo "FAIL build: warnings"; echo "$warnings"; exit 1; }
make -s -B -C "$ROOT" minifs || { echo "FAIL build"; exit 1; }
for c in ${*:-$ALL_CASES}; do
    if declare -F "$c" > /dev/null; then "$c"
    elif [ -f "$Q2/$c.txt" ]; then script_case "$c"
    else echo "FAIL $c (unknown case)"; failures=$((failures + 1)); fi
done
echo "$failures failure(s)"
[ "$failures" -eq 0 ]
```
